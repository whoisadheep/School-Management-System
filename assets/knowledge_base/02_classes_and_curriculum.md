# Classes, Sections & Curriculum Setup

> **Module**: Academic Management  
> **Sidebar Tab**: **Class & Section Setup**  
> **Deep Link**: `[NAV:classes]`  
> **Access**: Super Admin, Admin

---

## 1. Class Management

Classes represent standard grade levels (e.g., Nursery, Class 1, Class 10, Grade 12 - Science).

### How to Create a New Class
1. Navigate to **Class & Section Setup** from the sidebar.
2. In the **Add / Edit Class** card on the right or top of the screen:
   - Enter the **Class Name** (e.g., `Class 1`, `Grade 10`).
   - (Optional) Enter the **Room Number** and default **Monthly Tuition Fee**.
   - Select the academic stream if applicable (e.g., General, Science, Commerce).
3. Click the purple **Save Class** button.
4. The new class will immediately appear in the class list.

---

## 2. Section Management

Each class can contain one or more sections (e.g., Section A, Section B).

### How to Add Sections to a Class
1. In the **Class & Section Setup** screen, locate the target Class in the list.
2. Under the Sections column or in the **Section Setup** section:
   - Enter the **Section Name** (e.g., `A`, `B`, `Rose`).
   - Specify the **Maximum Student Capacity** (e.g., `40`).
   - Assign a **Class Teacher** from the staff dropdown.
3. Click **Add Section**.
4. Students can now be enrolled directly into this section during admission.

---

## 3. Class Subject Curriculum (Curriculum Setup)

Eduvia allows administrators to configure a tailored subject curriculum for every class. For example, *Class 1* can have *Mathematics, English, Hindi*, while *Class 11* can have *Physics, Chemistry, Biology, Mathematics*.

### How to Assign Subjects to a Class
1. Go to **Class & Section Setup** from the sidebar.
2. Locate the target class in the Class Management table.
3. Click the purple **"Subjects"** action button in the action column.
4. A **Curriculum Subjects** dialog will open showing all currently configured subjects for that class.
5. In the input fields:
   - **Subject Name**: Enter the full name (e.g., `Mathematics`, `English Grammar`, `Social Science`).
   - **Subject Code**: Enter a short unique code (e.g., `MATH101`, `ENG101`, `SCI101`).
6. Click **Add Subject**.
7. The subject is instantly saved and linked to that specific class.

### How to Delete a Subject from a Class
- In the same **Curriculum Subjects** dialog, click the red trash/delete icon next to any subject.
- Deleting a subject here removes it from future new exams for this class, but does not alter past historical exam records.

### How Class Subjects Connect to the Exam Module
- When creating a new exam in the **Exams & Performance Reports** tab, selecting a Class will **automatically pull in all subjects** configured in this curriculum.
- You can still remove or add individual subjects on a per-exam basis if a specific subject is not tested in that exam.

---

## 4. Timetable & Teacher Substitution

- **Creating Timetables**: Under the Timetable sub-section, select the Class and Section, then assign teachers and subjects to each daily period (Monday through Saturday).
- **Teacher Substitution**: If a teacher is absent or on leave, go to the Timetable view to assign an available substitute teacher to that period to prevent conflicting allocations.

---

## 5. FAQs & Troubleshooting

- **Q: Can two classes share the same subject name?**  
  *A:* Yes. Both Class 1 and Class 2 can have a subject named "Mathematics". Each class has its own independent subject curriculum record.
- **Q: Can I set up subjects without a subject code?**  
  *A:* If you leave the subject code blank, Eduvia will automatically generate a clean default code based on the subject name (e.g., "SCI" for "Science").
